PROJECT OVERVIEW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

A professional-grade testing framework implemented in Go for validating
Mixture-of-Experts (MoE) machine learning models written in PyTorch/Python.

Key Features:
  ✓ Cross-language testing (Go ↔ Python)
  ✓ Unit tests for model inference
  ✓ Regression tests with baseline management
  ✓ Automated PDF report generation
  ✓ CI/CD pipeline integration
  ✓ Performance benchmarking
  ✓ Professional documentation

HOW TO USE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Quick Start (5 minutes):

1. Navigate to unittest directory:
   cd unittest

2. Install dependencies (if not done):
   make install
   # or manually: go mod tidy && go get ...

3. Run the full suite:
   # Option A: Quick script
   ./run_tests.bat         (Windows)
   ./run_tests.sh          (Linux/Mac)

   # Option B: Full orchestrator
   go run cmd/test_runner/main.go

   # Option C: Manual
   go test -v ./... | tee test_output.txt
   go run cmd/report_generator/main.go

4. View the report:
   # Opens: reports/test_report_YYYY-MM-DD_HH-MM-SS.pdf


Advanced Usage:

• Run specific tests:
  go test -v -run TestModelInference ./internal/models

• Run only unit tests:
  make test-unit

• Run only regression tests:
  make test-regression

• Generate report from existing output:
  go run cmd/report_generator/main.go -input test_output.txt

• Clean generated files:
  make clean

• Check coverage:
  make coverage
